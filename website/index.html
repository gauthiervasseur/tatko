HOW TO PLAY

  1. 1

    INSERT A CSV

    Click LOAD CSV or drop a file anywhere on the window. Tatko sorts the columns into DIMENSIONS (text, dates, IDs) and MEASURES (numbers).

  2. 2

    DRAG FIELDS ONTO SHELVES

    Category to Columns, Revenue to Values, Region to Color, and you have a stacked bar chart. Click a pill to switch SUM to AVERAGE, or YEAR to MONTH.

  3. 3

    PIVOT, FILTER, WIN

    Choose TABLE for a pivot table, stack dimensions on rows and columns, turn on heat shading, and drop fields on Filters to zoom in on what matters.

CONTROLS

  • DRAG field → shelf: add it
  • DRAG pill off its shelf: remove it
  • DOUBLE-CLICK field: add it to the best shelf
  • RIGHT-CLICK field: more options
  • CLICK pill: aggregation or date level
  • CLICK table header: sort

ARCADE OUTSIDE. YOUR BRAND INSIDE.

The interface is always 1985. The charts and tables follow a CSS file you choose, using your palette, your fonts and your table style.

my-company.css
/* every line is optional */
@import url("https://fonts.googleapis.com/css2?family=Inter");

:root {
  --tatko-font-family: "Inter", sans-serif;
  --tatko-font-size: 13px;
  --tatko-text-color: #0b0b0b;
  --tatko-background: #ffffff;
  --tatko-grid-color: #e6e5e0;
  --tatko-palette: #2a78d6, #eb6834, #1baf7a, #eda100;
  --tatko-sequential: #cde2fb, #104281;
  --tatko-table-header-background: #0b0b0b;
  --tatko-table-header-color: #ffffff;
}

HOW IT WORKS

  • Load it with THEME CSS, or drop the .css file on the window.
  • Tatko reads --tatko-* variables, plus plain font-family, color and background on :root or body.
  • Web fonts work through @import or @font-face.
  • Up to 8 palette colors. Each value keeps its color when you filter, and extra values fold into "Other".
  • The THEME tab previews the result and flags anything it couldn't read.

WHY "TATKO"?

Татко (TAHT-ko) is Ukrainian for Daddy. Every arcade needs a player one, and Tatko's is pixelled from the real daddy himself.

FAQ

Can I open Excel files?
Save the sheet as CSV first (File › Save As › CSV). Tatko works with one CSV file at a time.
How big can the file be?
Tatko keeps the whole file in memory. On a recent laptop, a 300,000-row (10 MB) file loads in under a second and pivots redraw in a fraction of a second. Much larger files depend on your computer's memory.
Is my data uploaded anywhere?
No. Everything happens inside your browser, even in the online version.
